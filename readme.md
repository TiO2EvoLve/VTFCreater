# Source1 Engine VTF/VMT file Generator

## 系统需求
  
- Windows 64位 操作系统
- Windows 10 及以上系统

## 正常使用前提
① 首次运行需设置源文件夹路径，里面存放png源文件，程序要根据这些源文件及目录结构来生成对应的结果。

② 首次运行需设置输出文件夹路径，输出路径可以设为游戏内存放资源的位置。
推荐在主目录里建一个asset的文件夹，然后在gameinfo.txt里将文件夹添加到游戏资源里，这样既能存放自定义资产，又不会影响游戏原来的目录结构，能更好的区分开来。

③ 程序目录的dll文件存放生成vtf的关键，不能删除。

④ 贴图后缀需符合要求才能被识别，如带_color后缀则被识别为漫反射贴图，带_normal则被识别为法线贴图，后缀匹配可在设置里自行添加。

## 局限
① 目前仅支持识别漫反射贴图和法线贴图，因为其他贴图似乎不怎么常用。
② 受VTF贴图生成影响，贴图一多速度会明显变慢，所以建议已生成的源文件移到别处，不要堆积，会导致重复生成影响效率。
③ 目前仅搜索".png", ".jpg", ".jpeg", ".tga","bmp"格式的文件，应该也没用其他常用格式了吧
④ 透明贴图和普通贴图得分开生成，普通贴图选DXT1，透明贴图选DXT5，如果不在乎文件大小，可以一律选择DXT5，这样透明贴图和普通贴图可以一块生成。
